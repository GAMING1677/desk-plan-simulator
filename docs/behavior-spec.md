# 机上レイアウトの動作仕様

前提・操作・動作を機能別に記載。座標・色・呼出回数の詳細は対応テストで確認する。

## 起動と画面の連携

| Given（前提）              | When（操作・条件）       | Then（動作）                                                                         |
| -------------------------- | ------------------------ | ------------------------------------------------------------------------------------ |
| 初回起動                   | 画面を開く               | 空の初期配置から開始し、一覧・三面図・選択物の編集を表示する。                       |
| 物がある                   | 一覧・図で選択し編集する | 一覧または図で選択した物を編集対象にする。編集結果は一覧・図・保存データに反映する。 |
| 物がない／最後の物を選択中 | 起動／最後の物を削除する | 物がないときは未選択の案内を表示する。最後の物を削除した後も同じ状態に戻る。         |
| 編集・保存済み             | 初期化する               | 初期化は机・物・選択・編集エラー・保存状態を初期状態に戻す。                         |
| StrictMode有効             | 初期化を再実行する       | StrictModeの再実行で外部登録や描画資源を二重に残さない。                             |

対応テスト：BOOT / ENTRY / SIM / E2E-BOOT / E2E-EDIT。 / E2E-SPEC-03

## 机と物の入力

| Given（前提）        | When（操作・条件）                                        | Then（動作）                                                                                  |
| -------------------- | --------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 机寸法を編集中       | blur・Enter／Escapeで操作する                             | 机寸法はフォーカスを外すかEnterで確定する。Escapeでは未確定の変更を破棄する。                 |
| 名前を編集中         | 前後空白／空白だけの名前を入力する                        | 物の名前は前後の空白を除く。空白だけの名前へ変更しようとした場合は旧名を保つ。                |
| 机寸法の入力         | 0・負値・10,000cm・上限超過・非数値・無効な配置を指定する | 机の各寸法は有限・正、上限10,000cm。0以下・上限超過・非数値・配置を無効にする変更は拒否する。 |
| 物の寸法・高さの入力 | 寸法0／正値、高さ0／負値、有限／非有限の値を指定する      | 物の幅・奥行き・高さは有限・正。天板からの高さは有限・0以上。                                 |
| 入力エラーがある     | 不正入力／有効な再入力を行う                              | 拒否した入力は配置データを変えず、画面にエラーを表示する。有効な再入力でエラーを解除する。    |

対応テスト：EDITOR / SIDEBAR / INSPECT / E2E-EDIT。 / E2E-SPEC-01

## オブジェクトの追加と種類

| Given（前提）          | When（操作・条件）                       | Then（動作）                                                                                   |
| ---------------------- | ---------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 追加フォーム           | 種類・名前・寸法・載せ先・高さを指定する | 直方体・モニター・ポスター・ノートPCを追加できる。名前・寸法・載せ先・高さを指定する。         |
| 有効入力だが空きがない | 追加を試みる                             | 有効な入力でも、他の物と重ならない配置候補がなければ追加しない。画面に理由を表示する。         |
| 追加フォーム           | 有効／不正／配置不可の入力で追加する     | 追加した物を選択し、追加フォームを閉じる。入力が不正または配置不可なら追加ボタンを無効にする。 |
| 追加下書き             | 定型を選ぶ／寸法を手入力する             | 定型サイズを選ぶと種類・名前・寸法を反映する。寸法の手入力後は自由入力に戻る。                 |
| ポスターの追加下書き   | 寸法を編集・交換する                     | ポスターは固定厚みの薄板として扱う。奥行き欄を表示せず、幅と高さを交換できる。                 |
| ポスターの追加下書き   | 通常形状へ切り替える                     | ポスターから通常の形状に戻した際は通常の奥行きへ戻す。                                         |

対応テスト：ADD / EDITOR / PRESET / E2E-EDIT。 / E2E-SPEC-02

## 載せ先の指定とエラー

| Given（前提）                              | When（操作・条件）             | Then（動作）                                                                                         |
| ------------------------------------------ | ------------------------------ | ---------------------------------------------------------------------------------------------------- |
| 有効な載せ先がある                         | 独立配置／物の上を選ぶ         | 独立配置を選ぶと載せ先を解除する。物の上へ乗せると載せ先を指定し、台に接する高さへ変更する。         |
| 載せ先付きの物                             | 解除／同じ載せ先を再指定する   | 載せ先の解除は現在の世界位置を保つ。同じ載せ先を再指定する操作は成功扱いとし、不要な更新をしない。   |
| 自分・子・孫・ポスターがある               | 載せ先候補を表示／直接指定する | 自分自身・子・孫・ポスターは載せ先にできない。編集画面の候補にも表示しない。                         |
| 存在しないID・空ID・ID以外の型             | 載せ先として指定する           | 存在しない載せ先、空のID、ID以外の入力を拒否する。外部操作で指定された値も独立配置へ暗黙変換しない。 |
| 祖先に欠落・ポスター・循環がある           | 載せ先を指定する               | 載せ先の祖先まで確認し、途中の欠落・ポスター・循環も拒否する。                                       |
| 不正な載せ先                               | UIで変更する                   | UIでは拒否理由を表示し、対象入力を不正状態にする。配置と選択は変更しない。                           |
| 不正な載せ先                               | 外部ツールで変更する           | 外部ツールは理由付きエラーを返し、配置・選択・描画完了待ちを実行しない。                             |
| 下書きの載せ先が無効                       | 追加フォームを表示する         | 下書きの載せ先が無効になった場合も追加を無効にし、理由を表示する。                                   |
| null・空文字・自分・直接の子・複数段の子孫 | 載せ先を検証する               | nullは独立配置として受け付け、空文字・自分・子孫は拒否する。                                         |

対応テスト：MODEL-13〜18 / EDITOR-08 / ADD-03 / INSPECT-02〜03 / TOOLS-03〜06 / E2E-EDIT-02。 / E2E-SPEC-03〜04

## 台と物の削除

| Given（前提）            | When（操作・条件）   | Then（動作）                                                                                         |
| ------------------------ | -------------------- | ---------------------------------------------------------------------------------------------------- |
| 選択物がある             | 削除する             | 選択物だけを削除する。残る物へ選択を移し、物がなくなれば未選択にする。                               |
| 台に子・孫が載っている   | 台を削除する         | 台を削除した場合、直接乗っていた物を独立配置へ変更し、世界位置を保つ。さらに上の物は親子関係を保つ。 |
| 下書きの載せ先を選択中   | 載せ先の物を削除する | 下書きが削除した物を載せ先としていた場合は独立配置へ戻す。                                           |
| 削除後に配置が無効になる | 削除する             | 削除後の配置が無効になる場合は削除を拒否する。                                                       |

対応テスト：MODEL-21 / EDITOR-02,09 / INSPECT-04 / SIM-02 / E2E-EDIT-03。 / E2E-SPEC-03

## 配置と衝突

| Given（前提）                | When（操作・条件）                                                | Then（動作）                                                                                                             |
| ---------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 複数段の積載がある           | 世界位置を計算／親を移動する                                      | 載せ先を順にたどって世界位置を計算する。親の移動は子孫の配置検証にも影響する。                                           |
| 他の物がある                 | 面接触／正の体積の重なりを作る                                    | 物同士が正の体積で重なる配置を拒否する。面が触れるだけの配置は許可する。                                                 |
| 種類の異なる物がある         | 衝突判定する                                                      | 直方体・ノートPC・薄いポスター・モニターの画面／足／支柱を、それぞれの衝突形状で判定する。                               |
| 通常の物と机・台             | 支持面の重なりが正／0になる                                       | 机や台と面積が重なっていれば、物が台より大きくても配置できる。面積がない接触は通常の物では許可しない。                   |
| ポスター                     | 支持面からはみ出す／物と体積が重なる                              | ポスターは机や台からのはみ出しを許可するが、他の物との体積衝突は拒否する。                                               |
| 載せ先付きの物               | 配置を変更する                                                    | 載せ先付きの物は台に接する高さを保つ。                                                                                   |
| 無関係な旧配置に衝突がある   | 別の物を編集する                                                  | 編集によって影響を受ける物と子孫を検証する。無関係な旧配置の衝突で編集を止めない。                                       |
| 配置候補を検索する入力       | 空き位置を探す                                                    | 空き位置が見つかれば候補を返し、なければ追加不可にする。入力データを直接書き換えない。                                   |
| 面・支持面・高さ・数値の境界 | 接触／微小重なり、面積あり／なし、0／負値、有限／非有限を検証する | 面接触・正の支持面積・高さ0は許可し、体積の重なり・支持面積0・負の高さ・非有限値は拒否する（支持面積はポスターを除く）。 |

対応テスト：MODEL / EDITOR-07 / TOOLS / E2E-EDIT。 / E2E-SPEC-04〜05

## 三面図と表示

| Given（前提）                | When（操作・条件）             | Then（動作）                                                                   |
| ---------------------------- | ------------------------------ | ------------------------------------------------------------------------------ |
| 配置がある                   | 三面図を表示する               | 上面図は幅・奥行き、側面図は奥行き・高さ、正面図は固定視点の3Dとして表示する。 |
| 積載・はみ出し・高い物がある | 上面・側面を表示する           | 上面・側面は世界位置と積載順を反映し、はみ出した物や高い物も表示範囲に含める。 |
| 選択／不正な変更がある       | 表示状態・寸法表示を切り替える | 選択と不正な変更を色で区別する。寸法表示の切替は全図に適用する。               |
| 種類ごとの物がある           | 一覧・編集欄・図を表示する     | 種類ごとの名称・アイコンを一覧と編集画面で統一し、図では名称を省略する。       |

対応テスト：VIEWS / TOP / SIDE / FRONT / APPEAR / CONST。

## ドラッグと正面図のパン

| Given（前提）                        | When（操作・条件）                                           | Then（動作）                                                                                                    |
| ------------------------------------ | ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| 図の物を操作できる                   | 上面／側面／正面でドラッグする                               | 上面では平面位置、側面では奥行きと高さ、正面では画面上の移動を逆投影した横位置と高さを変更する。                |
| 物をドラッグ中                       | 位置を更新する                                               | 移動値は小数第1位へ丸める。高さは0未満にせず、載せ先付きの物の高さは変えない。                                  |
| 以前のエラー／衝突する移動先         | ドラッグを開始・移動する                                     | 衝突する移動は拒否する。ドラッグ開始時に物を選択し、以前のエラーを解除する。                                    |
| 正面図の背景／物                     | 主ポインターの左ボタンで開始する                             | 正面図の背景は左ボタンの主ポインターでパンする。物のドラッグと背景のパンを同時に開始しない。                    |
| 操作中のポインターがある             | 別のpointerIdで移動・終了／up・cancel・capture消失する       | 開始したポインター以外の移動・終了を無視する。up・cancel・capture消失で操作を終了する。                         |
| 操作が終了済み                       | ポインターを移動する                                         | 終了後にポインターを動かしても配置を更新しない。                                                                |
| 高さ下限・操作対象・ポインターの境界 | 右ボタン・非主ポインター・異なるID・開始前／終了後を検証する | 高さを0以上に保つ。異なるID・右ボタン・非主ポインターでは対象操作を実行せず、開始前・終了後は配置を更新しない。 |

対応テスト：DRAG / PAN / FRONT-03 / E2E-DIAGRAM。

## カメラと3D資源

| Given（前提）                           | When（操作・条件）              | Then（動作）                                                                                                  |
| --------------------------------------- | ------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 固定の水平視点                          | 倍率・パンを調整する            | 固定の水平視点を使い、倍率とパンで表示を調整する。パンは視点の位置を変えない。                                |
| 投影した世界位置                        | 同じ奥行きで逆投影する          | 投影と同じ奥行きでの逆投影は、数値誤差の範囲で元の世界位置へ戻る。                                            |
| 机と可視の物がある                      | 全体表示する                    | 全体表示は机と可視の物を画面内へ収める倍率と位置を選ぶ。                                                      |
| 描画済みのシーン                        | 変更／unmountする               | シーン変更時は再描画し、古いgeometryとmaterialを解放する。unmount時にrendererを解放する。                     |
| 重なった物／空白                        | 3D表示をクリックする            | 3Dのクリックは最前面の物に対応する。空白では物を選択しない。                                                  |
| WebGL非対応                             | 描画を開始する                  | WebGLを開始できない場合は画面に案内を表示し、起動例外を漏らさない。                                           |
| 倍率1〜200%・空配置・高い物・カメラ近傍 | 表示・再描画・unmountを検証する | 倍率の範囲を保ち、空配置・高い物でも全体表示できる。非対応時は案内し、再描画・unmountで不要な資源を解放する。 |

対応テスト：CAMERA / SCENE / E2E-BOOT-01 / E2E-DIAGRAM。 / E2E-SPEC-06

## 保存・読込

| Given（前提）                  | When（操作・条件）                                                                       | Then（動作）                                                                                                                 |
| ------------------------------ | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 現在の机・物・任意の名前       | 保存する                                                                                 | 現在の机・物・任意の名前を、対応する形式とバージョンのJSONへ保存する。                                                       |
| 保存名がある／空               | 保存する                                                                                 | 名前から安全なファイル名を作る。保存名が空なら保存せず理由を表示する。                                                       |
| 保存先API対応／未対応          | 保存する                                                                                 | 保存先の選択に対応していればファイルへ書き込み、未対応なら通常ダウンロードにする。                                           |
| 保存処理中                     | 取消／失敗する                                                                           | 保存取消は通常エラーと区別する。失敗後も処理中状態を解除する。                                                               |
| 保存済み                       | 配置を変更／一時資源の使用を終える                                                       | 保存後の変更を検出して保存済み表示を外す。一時リンクとObject URLを後始末する。                                               |
| 正常なファイル                 | 読み込む                                                                                 | 正常読込は机・物・名前・選択を更新し、下書きの載せ先と画面のエラーを整理する。                                               |
| 不正なファイル                 | 読み込む／同じファイルを再選択する                                                       | 不正読込は理由を表示し、元の配置を保つ。同じファイルを続けて選び直せる。                                                     |
| サイズ・件数・形式・配置の境界 | 5,000,000byte・1,000件の境界／超過、不正形式・版・JSON・寸法・ID・載せ先・衝突を読み込む | サイズ・件数の上限以下は他の条件も有効なら許容し、超過・不正形式・版・JSON・寸法・ID重複・載せ先欠落・循環・衝突は拒否する。 |
| 名前・机寸法の境界             | ファイル名幹80文字・読込名120文字・机寸法上限を検証する                                  | ファイル名の幹は80文字まで、読込内の名前は120文字まで。机寸法は入力と同じ上限を使う。                                        |

対応テスト：FILE / IO-01〜06 / HEADER / E2E-FILE-01〜02。 / E2E-SPEC-FILE / E2E-SPEC-07〜08

## 持ち物とPNGの書出し

| Given（前提）                                 | When（操作・条件）               | Then（動作）                                                                                                        |
| --------------------------------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 日本語・記号・改行を含む持ち物                | 一覧を書き出す                   | 持ち物は配置一覧の順序で番号付きMarkdownへ書き出す。改行を1行化し、Markdown記号をエスケープする。                   |
| 持ち物0件／物がある                           | コピー／全文選択する             | 空リストは空として表示し、コピーを無効にする。全文選択による手動コピーもできる。                                    |
| コピー可能な一覧                              | コピーする／失敗後に再試行する   | コピー中・成功・失敗を画面に表示する。失敗時は再試行または手動コピーを案内する。                                    |
| 正面図のSVG                                   | PNGを書き出す                    | 正面図は元SVGを変更せず、3Dcanvasを埋め込んだ白背景のFHD PNGへ変換する。                                            |
| 画像・canvas・クリップボードが非対応／失敗    | 書出しを実行する                 | 画像読込・canvas生成・画像書込・クリップボードの非対応や拒否を失敗として扱う。                                      |
| 0件・特殊文字・日本語・改行・canvasあり／なし | 一覧・画像の書出し境界を検証する | 0件ではコピーを無効にする。文字と行の意味を保ち、canvasは存在すれば含める。非対応・画像生成失敗はエラーとして扱う。 |
| Windowsのクリップボード                       | 改行コードが変換される           | Windowsのクリップボードは改行コードを変換する場合があるが、番号・名前・行の意味を保つ。                             |

対応テスト：INVENTORY / DIALOG / PNG / IO-07〜08 / E2E-FILE-03〜04。 / E2E-SPEC-09

## 外部操作ツール

| Given（前提）                                  | When（操作・条件）                    | Then（動作）                                                                      |
| ---------------------------------------------- | ------------------------------------- | --------------------------------------------------------------------------------- |
| 対応環境                                       | ツールを登録する                      | 読取・追加・移動・載せ先変更の4操作を公開する。読取だけを読取専用として登録する。 |
| 操作入力                                       | 型・必須値・載せ先を検証する          | 入力の型・必須値・載せ先を検証し、不正な操作は理由付きエラーを返す。              |
| 台に載った物                                   | 世界座標で移動する                    | 移動入力は世界座標で受け取り、台がある場合は相対座標へ変換する。                  |
| 有効な書込操作                                 | 操作に成功する                        | 成功した書込は対象物を選択し、画面更新完了を待って結果を返す。                    |
| ツール登録済み                                 | 配置変更・通常再描画が起きる          | 登録済み操作は常に最新の配置を参照する。通常の再描画では不要な再登録をしない。    |
| 非対応／登録失敗／登録済み                     | 起動／終了する                        | 非対応環境で登録しない。登録失敗は起動を妨げず、終了時は登録を解除する。          |
| null・配列・文字列・欠落ID・非数値・無効載せ先 | 操作／同期例外・Promise拒否を検証する | 不正入力を理由付きで拒否する。登録時の同期例外・Promise拒否も起動を妨げない。     |

対応テスト：TOOLS / REGISTER / create-layout-tools.test.mjsの既存7件。 / E2E-SPEC-04,10

## 共通UIと画面幅

| Given（前提）                                         | When（操作・条件）                | Then（動作）                                                                                   |
| ----------------------------------------------------- | --------------------------------- | ---------------------------------------------------------------------------------------------- |
| 共通ボタン・入力・選択部品                            | 属性・値・イベント・refを渡す     | ボタン・入力・選択部品は属性、値、イベント、refを実要素へ引き継ぐ。                            |
| enabled／disabled・装飾アイコン                       | クリック・キーボードで操作する    | disabledの操作を実行せず、キーボードで操作できる。装飾アイコンは読み上げやクリックを妨げない。 |
| 条件付き・競合するクラス                              | クラスを結合する                  | クラス指定は条件付き値を結合し、競合する指定を後から渡した指定で解決する。                     |
| 広い／狭い画面                                        | 主要操作を使う                    | 広い画面と狭い画面の両方で主要操作へ到達でき、意図しない横はみ出しを起こさない。               |
| dialog・保存パネル                                    | 入力・取消・実行へ移動する        | dialogと保存パネルは入力・取消・実行へ到達でき、フォーカスを視認できる。                       |
| 制御／非制御・button／asChild・disabled・グループ選択 | 1440×900／390×844で操作を検証する | 各形式で値・イベントを引き継ぎ、disabledは実行しない。両画面幅で主要操作へ到達できる。         |

対応テスト：BUTTON / INPUT / SELECT / CLASS / E2E-VISUAL。

## 型・ビルド・静的資産

| Given（前提）                           | When（操作・条件）       | Then（動作）                                                                                         |
| --------------------------------------- | ------------------------ | ---------------------------------------------------------------------------------------------------- |
| 全実行ファイル／型ファイル              | テスト一覧・型を確認する | アプリの全実行ファイルに対応するテストを持つ。型だけのファイルは型チェックで確認する。               |
| React・エイリアス・スタイルを使うアプリ | 本番ビルドする           | Reactとエイリアスを解決して本番成果物を作る。Tailwindと自作スタイルを適用する。                      |
| HTML入口・メタ情報・静的資産            | 起動する                 | HTML入口・メタ情報は画面の初期状態と矛盾せず、参照する画像とファイルが存在する。                     |
| 全種類のテスト                          | 一括実行する             | 単体・UI・既存ツール・実ブラウザのテストを一括実行できる。失敗があればコマンドを失敗として終了する。 |

対応テスト：BUILD / E2E-BOOT / 型チェック / 本番ビルド / test:inventory。

## テストや仕様を変更するとき

| Given（前提）                | When（操作・条件）             | Then（動作）                                                                            |
| ---------------------------- | ------------------------------ | --------------------------------------------------------------------------------------- |
| 動作を変更する               | テストを修正する               | 動作を変更したら、この文書の該当項目と対応するIDのテストを両方修正する。                |
| 境界を変更する               | 境界のケースを修正する         | 境界を変更したら、許容側・拒否側・ちょうど境界のケースを確認する。                      |
| 動作・境界が同じ             | fixture・数値精度だけ変更する  | テストのfixtureや数値精度だけを変更し、動作と境界に変更がなければ仕様の書き換えは不要。 |
| この文書を変更した           | npm run docs:specを実行する    | 文書を変更した後はnpm run docs:specでHTMLを更新する。テストから文章を自動生成しない。   |
| 実装・テストを変更した       | 検証・基準画像の更新を行う     | npm test、npm run buildを実行する。画像差分は目視で確認してから基準画像を更新する。     |
| ブラウザを初めて用意する環境 | npm run test:installを実行する | ブラウザを初めて用意する環境ではnpm run test:installを実行する。                        |
