# 仕様とE2Eの対応

公開前は本番ビルドに対して実行する。内部の数値計算・資源解放・全種類の不正入力は単体／フックテストで補完する。

| 仕様の機能       | E2E                                             | 確認する動作・境界                                                                           |
| ---------------- | ----------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 起動と画面の連携 | E2E-BOOT、E2E-EDIT-01、E2E-SPEC-03              | 空配置、三面図、選択、同期、初期化、最後の物の削除                                           |
| 机と物の入力     | E2E-SPEC-01、E2E-EDIT-03                        | Enter・blur・Escape、名前空白、寸法0・負値・上限・超過、エラー回復                           |
| 追加と種類       | E2E-EDIT-01、E2E-SPEC-02                        | 4種類、無効入力、定型・自由入力、ポスター寸法交換・奥行き切替                                |
| 載せ先とエラー   | E2E-EDIT-02、E2E-SPEC-03〜04                    | 子孫・ポスターの候補除外、独立配置、世界位置保持、無効ID・型・自己・子孫の拒否               |
| 削除             | E2E-EDIT-03、E2E-SPEC-03                        | 子孫の世界位置、親子関係、0件の未選択                                                        |
| 配置と衝突       | E2E-SPEC-04〜05、E2E-EDIT-02                    | 相対座標、面接触・微小重なり、支持面積あり・なし、拒否時の配置保持                           |
| 三面図と表示     | E2E-BOOT-01、E2E-DIAGRAM-03、E2E-VISUAL         | 表示、寸法切替、積載と種類、広い・狭い画面                                                   |
| ドラッグとパン   | E2E-DIAGRAM-01〜03                              | 実SVG変換、raycast、正面逆投影、操作終了後の保持、背景パン                                   |
| カメラと3D       | E2E-DIAGRAM-02〜03、E2E-SPEC-06                 | 実WebGL、倍率、全体表示、非対応時の案内と他機能の操作                                        |
| 保存・読込       | E2E-FILE-01〜02、E2E-SPEC-FILE、E2E-SPEC-07〜08 | 往復・再選択、保存状態、取消・拒否・再試行、形式・ID・載せ先・衝突、サイズ・件数・名前の上限 |
| 持ち物・PNG      | E2E-FILE-03〜04、E2E-SPEC-09                    | 実PNG生成、日本語・記号、コピー失敗と回復、0件                                               |
| 外部ツール       | E2E-SPEC-04、E2E-SPEC-10                        | 最新状態、世界座標、拒否時の保持、登録失敗でもUI編集可能                                     |
| 共通UI・画面幅   | E2E-VISUAL、E2E-SPEC-01〜02                     | disabled、入力イベント、フォーカス、主要操作への到達、横はみ出し                             |
| ビルド・静的資産 | E2E-BOOT-02、CI Build and all tests             | 本番成果物、画像とメタ情報、全テスト成功時だけ公開                                           |

## 公開の条件

| Given（前提）            | When（操作・条件）                                        | Then（動作）                                           |
| ------------------------ | --------------------------------------------------------- | ------------------------------------------------------ |
| PRまたは作業ブランチ     | 変更をpushする                                            | ビルドと全テストを実行し、本番公開しない。             |
| mainへpush               | ビルド・単体・UI・フック・既存ツール・E2Eがすべて成功する | 同じ実行のテスト済みdistをCloudflare Pagesへ公開する。 |
| 検証に失敗／取消         | 公開条件を判定する                                        | 公開ジョブを実行せず、失敗時は診断資料を保存する。     |
| 手動でワークフローを実行 | 検証に成功する                                            | 検証だけを行い、本番公開しない。                       |
